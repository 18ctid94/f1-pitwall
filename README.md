# PITWALL
Unofficial, non-commercial F1 career companion for the 2025 and 2026 game editions. Track race weekends, results and driving references locally. No affiliation with Formula 1, FIA, EA or teams.

Run `npm install` and `npm run build` to build. GitHub Pages hosts the static application. Export JSON backups from Settings. See THIRD_PARTY_NOTICES.md for attribution.
